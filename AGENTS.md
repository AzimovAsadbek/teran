## O‘zgarish kiritishda

1. **Savdo rejimini aniqlab ol.** Narxlar yopiq rejimda mahsulotdan `/contact?tea=…` orqali murojaat yuboriladi. Narxlar ochiq rejimda `tea` turkumi va uning ichidagi choylar uchun savat, buyurtma va ombor rezervi ishlaydi. Boshqa turkumlar aloqa orqali buyurtma oladi. Mehmon choyni savatga qo‘sha oladi. Buyurtmani tasdiqlash uchun hisobga kirish shart, kirilganda savat saqlanadi. `NEXT_PUBLIC_SHOW_PRICES` web yig‘ilayotganda, `CHECKOUT_ENABLED` API ishga tushganda o‘qiladi. Demo kontenti va qidiruv tizimlarida indekslanish alohida sozlanadi. [Vitrina sozlamalari](apps/web/src/lib/site.ts) · [API tekshiruvi](apps/api/src/orders/checkout-enabled.guard.ts) · [Indekslash](apps/web/src/lib/seo/indexing.ts)
2. **Ma’lumot shartnomasidan boshla.** Kiruvchi maydon yoki javob o‘zgarsa, Zod sxemasi, API, web iste’molchisi va saqlangan eski yozuvlarni birga ko‘r. Narx, qoldiq va to‘lov holatini server belgilaydi. Buyurtma, to‘lov urinishi va `InventoryMovement` yozuvlari o‘zaro mos qolishini tekshir. Ayrim cheklovlar faqat SQL migratsiyalarida berilgan. [Shartnomalar](packages/contracts/src) · [Migratsiyalar](apps/api/prisma/migrations) · [To‘lov qoidalari](docs/architecture/payments.md)
3. **O‘zgarishni foydalanuvchigacha kuzat.** Admin saqlagan ma’lumotning tegishli tilda vitrinaga chiqishini tekshir. Keshga yoziladigan ommaviy ma’lumot va cookie bilan o‘qiladigan shaxsiy ma’lumot alohida yuklanadi. Standart o‘zbekcha manzil prefikssiz, ruscha va inglizcha manzillar `/ru` va `/en` bilan boshlanadi. Web kodini tahrirlashda mahalliy Next.js ko‘rsatmasini ham o‘qi. [API klienti](apps/web/src/lib/api/server.ts) · [Tarjimalar](apps/web/messages) · [Web uchun AGENTS.md](apps/web/AGENTS.md)
4. **Takroriy urinishni hisobga ol.** Savat, buyurtma, fayl yoki to‘lovga tegishli o‘zgarishda javob kechikishi, bir so‘rov takrorlanishi yoki ikki xodim bir vaqtda ishlashini tekshir. Kutiladigan natijani baza yozuvi, xaridor ko‘radigan holat va tarix yozuvi orqali tasdiqla. [API integratsion testlari](apps/api/test) · [Brauzer ssenariylari](e2e/tests)

5. **Birinchi ekrandagi videoni haqiqiy tarmoq cheklovi bilan tekshir.** `E2E_STORE_MODE` build va ishga tushirishda mos bo‘lsin. Bosh sahifaga video o‘rnatilgan sinov nusxasida `FILM_BENCH_URL` va `FILM_BENCH_RUNS=3`ni berib, `pnpm --filter @teran/e2e exec node scripts/measure-film.ts`ni bajar. Poster va birinchi harakatlanuvchi kadrni alohida o‘lcha. Mobil va keng nusxani, Save-Data’ni, kamaytirilgan harakat sozlamasini va ijroni qayta yoqishni tekshir. [Video o‘lchovlari](docs/performance-audit.md#2026-11-21-video-startup)

## Tekshiruvni tanlash

- Muhit uchun Node `>=24.15.0` va `package.json`dagi pnpm versiyasidan foydalan. `pnpm` buyrug‘i topilmasa, loyiha tavsiya qilgan `corepack enable` orqali uni `PATH`da mavjud qil. Ichki skriptlar ham `pnpm`ni nomi bilan chaqiradi. [Ishga tushirish](docs/development/setup.md) · [Buyruqlar](package.json)
- Toza checkoutda `pnpm install --frozen-lockfile` va `pnpm generate`dan keyin `pnpm lint`, `pnpm typecheck`, `pnpm test`ni ishga tushir. Umumiy format uchun `pnpm format:check`, bog‘liqliklar yangilanganda `pnpm audit:prod` ishlatiladi. Mahalliy agent fayllari yoki ichki worktree format natijasiga aralashsa, Git kuzatadigan fayllarni alohida tekshir. [CI ketma-ketligi](.github/workflows/ci.yml)
- Baza bilan bog‘liq o‘zgarishda `pnpm test:integration`ni alohida `*_test` bazasida bajar. Brauzer uchun `pnpm --filter @teran/e2e build:stack`, keyin `pnpm test:e2e` ishlatiladi. E2E tayyorlash skripti o‘z bazasini bo‘shatadi. Bunga alohida `*_e2e` bazasi ajrat. Narxsiz vitrinani tekshirishda build va test uchun `E2E_STORE_MODE=closed`ni ber. Narxli rejim uchun `open` ishlatiladi. Video konvertatsiyasi uchun `ffmpeg` va `ffprobe` kerak. [Integratsion muhit](apps/api/test/test-env.ts) · [Playwright sozlamasi](e2e/playwright.config.ts) · [Baza tayyorlash](e2e/scripts/prepare-db.ts)
- Natijani qayd etishda commit, savdo rejimi, muvaffaqiyatsiz va o‘tkazib yuborilgan testlarni ko‘rsat. Oldingi QA va Lighthouse hisobotlarini o‘z sanasidagi o‘lchov sifatida ishlat. [Sinov strategiyasi](docs/testing/test-strategy.md) · [Samaradorlik o‘lchovlari](docs/performance-audit.md)
